# Decode Labs - Project 3: E-Commerce SQL Data Analysis

## 📌 Project Overview
Following the data extraction, cleaning, and descriptive statistics phases completed in previous intern projects, **Project 3** focuses entirely on the database analytical tier. Using a standardized e-commerce dataset loaded into a **MySQL Relational Database Management System (RDBMS)**, this project executes key diagnostic queries, multi-level segmentations, high-value filters, and baseline aggregations to simulate standard corporate Business Intelligence workflows.

---

## 🛠️ Database Setup & Schema Configuration
- **Database System:** MySQL Workbench
- **Target Schema:** `decode_labs_project3`
- **Target Data Table:** `` `decode labs dataset` ``
- **Standardized Attributes Monitored:**
  - `Cleaned_Order_ID` (Text - Primary Transaction Key)
  - `Cleaned_Customer_ID` (Text - Relational Entity Key)
  - `Cleaned_Products` (Text - Categorical Dimension)
  - `Quantity` (Integer - Order Volume Metric)
  - `UnitPrice` (Decimal/Float - Pricing Metric)

## 💻 Complete Production SQL Script
Below is the unified SQL workflow containing all 8 operational analytical steps required for the Decode Labs assessment. Copy and execute this complete script inside your SQL editor:

```sql
-- =========================================================================
-- DECODE LABS: PROJECT 3 - E-COMMERCE SQL DATA ANALYSIS & BUSINESS INSIGHTS
-- =========================================================================
-- Author: Data Analyst Intern
-- Description: End-to-end data exploration, filtering, and aggregation 
--              to extract key retail metrics from the cleaned dataset.
-- =========================================================================

-- Step 1: Basic Data Retrieval (Verify Uploaded Columns)
-- Retrieve the first 10 rows to inspect the structure of the cleaned dataset
SELECT * 
FROM `decode labs dataset` 
LIMIT 10;

-- Step 2: High-Volume Transaction Filtering (WHERE Clause)
-- Filter transactions where the product quantity sold is 5 or more
SELECT Cleaned_Order_ID, Cleaned_Customer_ID, Cleaned_Products, Quantity, UnitPrice 
FROM `decode labs dataset`
WHERE Quantity >= 5;

-- Step 3: Global Macro Aggregations (Total Orders & Overall Revenue)
-- Calculate the total number of orders and the total overall revenue generated
SELECT 
    COUNT(Cleaned_Order_ID) AS Total_Orders,
    SUM(Quantity * UnitPrice) AS Total_Revenue
FROM `decode labs dataset`;

-- Step 4: Product Performance Matrix (GROUP BY Segmentations)
-- Group sales data by product to calculate total units sold and revenue per item
-- Sorted in descending order to identify the top-performing products
SELECT 
    Cleaned_Products AS Product,
    SUM(Quantity) AS Total_Units_Sold,
    SUM(Quantity * UnitPrice) AS Revenue_Generated
FROM `decode labs dataset`
GROUP BY Product
ORDER BY Revenue_Generated DESC;

-- Step 5: Transactional Basket Evaluation (AVG Analysis)
-- Calculate the average spending per transaction across the dataset
SELECT 
    AVG(Quantity * UnitPrice) AS Average_Order_Value
FROM `decode labs dataset`;

-- Step 6: Customer Intelligence Analysis (Top Spenders Identification)
-- Group by customer ID to find the total revenue generated by each individual customer
-- Sorted in descending order to highlight the top 10 highest-spending VIP profiles
SELECT 
    Cleaned_Customer_ID AS Customer_ID,
    COUNT(Cleaned_Order_ID) AS Total_Orders_Placed,
    SUM(Quantity * UnitPrice) AS Total_Amount_Spent
FROM `decode labs dataset`
GROUP BY Cleaned_Customer_ID
ORDER BY Total_Amount_Spent DESC
LIMIT 10;

-- Step 7: High-Value Threshold Analytics (HAVING Filtering)
-- Aggregate sales by product but only display products crossing a $5,000 threshold
SELECT 
    Cleaned_Products AS Product_Name,
    SUM(Quantity * UnitPrice) AS Total_Revenue
FROM `decode labs dataset`
GROUP BY Cleaned_Products
HAVING Total_Revenue > 5000
ORDER BY Total_Revenue DESC;

-- Step 8: Multi-Level Ordering Strategy
-- Retrieve transactions sorted primarily by largest quantity, secondarily by highest unit price
SELECT Cleaned_Order_ID, Cleaned_Products, Quantity, UnitPrice
FROM `decode labs dataset`
ORDER BY Quantity DESC, UnitPrice DESC
LIMIT 20;
